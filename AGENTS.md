## How to report back

Short and scannable, with emoji as the marker. One line each, no detail, no
reasoning, no next-step essay -- the owner asks when they want more.

- ✅ what was fixed.
- 📝 TODO: work that is understood and simply not done yet. Say what and when.
- ❓ NEEDS CLARIFICATION: blocked on the owner, with the actual question.

Never report a vague "missing". If nothing stops it, fix it instead of listing
it; if something stops it, that is either a TODO with an owner or a question, and
the line has to say which and ask it plainly.

**Short is not the same as clipped.** Each line is a plain English sentence, the
way you would say it out loud. No telegraphese, no stacked noun phrases, and no
line that is mostly ids, slugs and numbers -- the owner reads that as gibberish
and has said so. Name the thing in words first ("publishing one course at a time
now works"), and put the tracker id, the course slug or the commit hash after it,
where it is a reference rather than the sentence.
